# SmartLearn web client

This is the React and Vite frontend for SmartLearn LMS. It uses Redux Toolkit Query to load authenticated user, course, lesson, learner, assignment, and grade data from the Express API.

## Start the client

From this directory:

```sh
npm install
npm run dev
```

The API defaults to `http://localhost:8080/api/v1`. To use another API host, copy `.env.example` to `.env` and set `VITE_API_URL`.

## Available workspaces

- **Student:** learning home, course catalog, enrolled courses, lesson progress, schedule, announcements, course discussion, quizzes, assignment uploads, gradebook, and profile/password controls.
- **Teacher:** overview, course studio, lesson/video authoring, resources, quizzes, announcements, discussion, assignment creation and grading, learner roster and progress, and profile/password controls.
- **Admin:** platform overview, course and instructor assignment, people, account activation and role management, reports, and profile/password controls.

All workspaces use the Express API and MongoDB-backed data. The client sends the HTTP-only session cookie with API requests and refreshes cached course, assignment, user, quiz, announcement, and message data after changes.

The account-link pages are `/reset-password` and `/verify-email`. They open from the one-time links generated by the API.

For the full feature inventory, role permissions, end-to-end business workflow, server setup, API map, and deployment notes, read the [project README](../README.md).
